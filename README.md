# Source Code Management System

## File order
- `index.html` — page structure and forms.
- `css/style.css` — colors, layout, responsive design.
- `js/app.js` — navigation, repository CRUD, sample commit history, rendering, and localStorage.

## Run the project
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click `index.html` to open it in Chrome/Edge, or use VS Code Live Server.
4. Use Repositories to add/edit/delete demo repositories and Commit History to record sample commits.

## Scope
This is a front-end educational prototype. It does not execute real Git commands, connect to GitHub, or include authentication or a server database. Data is stored in the browser's localStorage.
